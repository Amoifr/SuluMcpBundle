From src/Tool/PageGetTool.php:
- Pattern: constructor(PageRepositoryInterface, ContentManagerInterface)
- Uses: getOneBy(['uuid' => $uuid, 'locale' => $locale, 'stage' => STAGE_DRAFT], [GROUP_SELECT => true])
- Then: contentManager->resolve() + normalize()
- Returns: ['uuid' => ..., 'data' => $normalized] or ['error' => ...]

From src/Tool/PageCreateTool.php:
- Pattern: HandleTrait + constructor(MessageBusInterface, ContentManagerInterface)
- $this->messageBus assigned in constructor body (NOT constructor promotion)
- Dispatches: new Envelope($message, [new EnableFlushStamp()])
- Returns resolved+normalized result

From src/Tool/PageUpdateTool.php:
- Pattern: reads current state first, merges changes, dispatches ModifyPageMessage
- Has normalizeContent() static helper for AI client input normalization

From src/Tool/PageDeleteTool.php:
- Pattern: HandleTrait + constructor(MessageBusInterface)
- Dispatches RemovePageMessage, returns success/error

From src/Tool/PageListTool.php:
- Pattern: repository findBy() with filters, countBy() for total, iterate+resolve+normalize

Article-specific interfaces (from RESEARCH.md, verified from vendor):
- ArticleRepositoryInterface: getOneBy(filters, selects), findBy(filters, sortBy, selects), countBy(filters)
- GROUP_SELECT_ARTICLE_ADMIN constant for selects
- ArticleNotFoundException for error handling
- CreateArticleMessage(array $data) -- NO webspace, NO parentId, $data['locale'] required
- ModifyArticleMessage(array $identifier, array $data)
- RemoveArticleMessage(array $identifier, string $locale)
- Filters for findBy(): locale, stage, templateKeys, categoryIds, tagNames, tagOperator, page, limit

From tests/Unit/Tool/PageCreateToolTest.php:
- Pattern: setUp() creates mocks, tests dispatch, tests error handling, tests MCP attribute
- Uses: createMock(MessageBusInterface::class), HandledStamp for return values
