Tag interfaces (from RESEARCH.md, verified from vendor):
- TagManagerInterface (Sulu\Bundle\TagBundle\Tag\TagManagerInterface):
  - save(array $data, ?int $id = null): TagInterface -- $data = ['name' => $name]
  - delete(int $id): void
  - findById(int $id): TagInterface
  - findByName(string $name): TagInterface
  - findOrCreateByName(string $name): TagInterface
  - NO list/findAll method -- use repository instead
- TagRepositoryInterface (Sulu\Bundle\TagBundle\Tag\TagRepositoryInterface):
  - extends Doctrine ObjectRepository -- provides findAll(), findBy(), find()
- TagInterface: getId(), getName()

Category interfaces (from RESEARCH.md, verified from vendor):
- CategoryManagerInterface (Sulu\Bundle\CategoryBundle\Category\CategoryManagerInterface):
  - save(array $data, ?int $userId, string $locale, bool $patch = false): ApiCategory
  - delete(int $id): void
  - findChildrenByParentId(?int $parentId = null): array -- null = full tree
  - getApiObjects(array $categories, string $locale): array -- wraps entities for output
  - $data for save: ['name' => $name, 'key' => $key, 'parent' => $parentId, 'locale' => $locale]
- ApiCategory: getId(), getName(), getKey(), getChildren()

User ID requirement (Pitfall 3 from RESEARCH.md):
- CategoryManagerInterface::save() requires $userId parameter
- MediaManagerInterface::save() also requires $userId
- Obtain via: TokenStorageInterface->getToken()->getUser()->getId()
- Inject: Symfony\Component\Security\Core\Authentication\Token\Storage\TokenStorageInterface
</interfaces>
