<interfaces>
<!-- Three distinct service patterns in this plan -->

Media interfaces (from RESEARCH.md, verified from vendor):
- MediaManagerInterface (Sulu\Bundle\MediaBundle\Media\Manager\MediaManagerInterface):
  - get(string $locale, array $filter = [], ?int $limit = null, ?int $offset = null): array -- returns Api\Media objects
  - getCount(): int -- count from last get() call
  - getById(int $id, string $locale): Api\Media
  - save(?UploadedFile $uploadedFile, array $data, ?int $userId): Api\Media -- null uploadedFile + data['id'] = metadata update
- Filter keys: collection (int), types (array), search (string), ids (array), orderBy, orderSort
- NO tag filtering at repository level (Pitfall 6)
- Api\Media: getId(), getTitle(), getMimeType(), getSize(), getUrl(), getFormats() (format URLs)

Snippet interfaces (from RESEARCH.md):
- SnippetRepositoryInterface (Sulu\Snippet\Domain\Repository\SnippetRepositoryInterface):
  - getOneBy(array $filters, array $selects): SnippetInterface
  - findBy(array $filters, array $sortBy, array $selects): iterable
  - countBy(array $filters): int
  - GROUP_SELECT_SNIPPET_ADMIN constant
  - Filters: same as articles (locale, stage, templateKeys, page, limit)
- Snippets are GLOBAL -- no webspace parameter (RESEARCH finding)
- Uses ContentManagerInterface resolve/normalize (same as pages/articles)

Contact interfaces (from RESEARCH.md):
- ContactRepositoryInterface (Sulu\Bundle\ContactBundle\Entity\ContactRepositoryInterface):
  - findGetAll(?int $limit, ?int $offset, array $sorting, array $where): array
  - findById(int $id): Contact
- AccountRepositoryInterface (Sulu\Bundle\ContactBundle\Entity\AccountRepositoryInterface):
  - findById(int $id): ?AccountInterface
  - findByIds(array $ids): array
  - findAllSelect(array $fields): array
- ContactBundle is present in Sulu 3.0 but tools should handle absence gracefully (Pitfall 7)

Navigation interface (from RESEARCH.md):
- NavigationRepositoryInterface (Sulu\Page\Domain\Repository\NavigationRepositoryInterface):
  - getNavigationTree(string $navigationContext, string $locale, string $webspaceKey, ?string $segmentKey, int $depth, array $properties): array
  - $navigationContext: "main", "footer" etc. (defined in webspace XML)

TokenStorageInterface needed for MediaUpdateTool userId (same as CategoryCreateTool):
- Symfony\Component\Security\Core\Authentication\Token\Storage\TokenStorageInterface
</interfaces>
