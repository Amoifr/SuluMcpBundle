Testing HandleTrait dispatch pattern:
The mock for MessageBusInterface::dispatch() should use a callback to capture the Envelope, inspect its message, and return a new Envelope wrapping a HandledStamp with the mocked result. Example:
```php
$this->messageBus->expects($this->once())
    ->method('dispatch')
    ->willReturnCallback(function (Envelope $envelope) use ($mockPage) {
        $message = $envelope->getMessage();
        $this->assertInstanceOf(CreatePageMessage::class, $message);
        return $envelope->with(new HandledStamp($mockPage, 'handler'));
    });
```
Use `Symfony\Component\Messenger\Stamp\HandledStamp` to provide the return value.
