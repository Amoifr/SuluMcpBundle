**GuidelineGeneratorPrompt.php** (per D-13, deferred from Phase 2 D-15):

```php
declare(strict_types=1);
namespace Sulu\McpServerBundle\Prompt;

use Mcp\Capability\Attribute\McpPrompt;

class GuidelineGeneratorPrompt
{
    #[McpPrompt(
        name: 'sulu_generate_guidelines',
        description: 'Guides the AI through analyzing existing pages in a webspace to generate content guidelines. The AI will read pages, analyze their tone, style, and audience, then save guidelines using sulu_update_guidelines.',
    )]
    public function generateGuidelines(string $webspace, string $locale): array
    {
        $promptText = <<<PROMPT
You are analyzing the content of the "{$webspace}" webspace (locale: {$locale}) to generate content guidelines.

Follow these steps:

1. **Discover pages**: Call `sulu_page_list` with webspace="{$webspace}" and locale="{$locale}" to get all pages.

2. **Read sample pages**: Call `sulu_page_get` for at least 3-5 pages to read their full content. Choose pages of different templates to get a representative sample.

3. **Analyze the content**: Look for patterns in:
   - **Tone**: Is the writing formal, casual, technical, friendly, authoritative?
   - **Audience**: Who is the content written for? (professionals, consumers, developers, etc.)
   - **Style**: Sentence length, paragraph structure, use of headings, lists, CTAs
   - **Brand voice**: Recurring phrases, terminology, how the organization refers to itself
   - **Do's**: Common positive patterns to follow
   - **Don'ts**: Patterns to avoid or that are notably absent

4. **Generate guidelines**: Based on your analysis, formulate clear, actionable guidelines.

5. **Save the guidelines**: Call `sulu_update_guidelines` with:
   - webspace="{$webspace}"
   - tone=[your analysis of the tone]
   - audience=[your analysis of the audience]
   - style=[your analysis of the style]
   - brandRules=[key brand voice rules you identified]
   - dos=[positive patterns to follow]
   - donts=[patterns to avoid]

Keep each field concise (under 300 characters each) so the total stays within the recommended 2000-character limit.
PROMPT;

        return [
            [
                'role' => 'user',
                'content' => [
                    ['type' => 'text', 'text' => $promptText],
                ],
            ],
        ];
    }
}
```
